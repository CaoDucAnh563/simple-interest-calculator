# Simple Interest Calculator

## Overview
This repository provides the formula and explanation for calculating Simple Interest.

## Formula
The basic formula to compute Simple Interest is:
$$I = P \times r \times t$$

Where:
- **P** = Principal amount (Tiền gốc)
- **r** = Annual interest rate (Lãi suất hàng năm dưới dạng thập phân, ví dụ 5% = 0.05)
- **t** = Time in years (Thời gian tính bằng năm)
- **I** = Total Interest accrued (Tiền lãi)

### Total Balance
$$A = P + I = P(1 + r \times t)$$

## Sample Calculation
If $P = 1000$, $r = 0.05$ (5%), and $t = 3$ years:
- $I = 1000 \times 0.05 \times 3 = 150$
- Total Amount ($A$) = $1000 + 150 = 1150$
